# Portfolio

![Version](https://img.shields.io/badge/version-1.0.0-00C853)
![Status](https://img.shields.io/badge/status-stable-success)

Personal portfolio developed to showcase my projects, technical skills and experience as a Full Stack Developer.

The website was designed with a strong focus on clean design, smooth user experience and performance, serving as a central hub for recruiters, clients and collaborators.

## Design Goals

The project was built following three principles:

- Clean visual identity
- Smooth user interactions
- Easy maintenance and scalability

Every component was developed focusing on readability, consistency and modularity.
